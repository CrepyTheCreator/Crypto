⚡ ExAmple — платформа аренды энергии и стейкинга TRX

> Функциональный веб-сервис для работы с TRX, предоставляющий возможности аренды энергии, расчёта доходности и стейкинга. Реализованы все страницы, указанные в шапке сайта: **Главная, Стейкинг, Реферальная программа, API, FAQ*.

🌟 Основные возможности

- 📦 Аренда энергии TRON с моментальным расчётом и скидкой
- 📈 Калькулятор доходности в TRX и $
- 💰 Стейкинг с пассивным доходом до 22% годовых
- 👥 Поддержка реферальной системы
- 🧩 API-интеграция
- 📄 Раздел FAQ и подробная информация о компании

🔧 Стек технологий

- HTML5 + CSS3 (адаптивная вёрстка)
- JavaScript ES6+
- Анимации на чистом CSS
- SVG-графика
